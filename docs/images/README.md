# 截图目录

README 里引用的图片都放在这里。把你自己的截图按下面的文件名放进来即可自动显示，**不需要改 README**。

README 里按「左浅色 / 右深色」两列并排展示，共 6 张：

| 文件名 | 用途 | 建议尺寸 |
|---|---|---|
| `screenshot-light.png` | 测速界面 · 浅色 | 宽 1700 左右 |
| `screenshot-dark.png` | 测速界面 · 深色 | 宽 1700 左右 |
| `history-light.png` | 历史记录 · 浅色 | 宽 1700 左右 |
| `history-dark.png` | 历史记录 · 深色 | 宽 1700 左右 |
| `phone-screenshot.jpg` | 手机端测速界面 | 宽 1280 左右（实机截图） |
| `phone-history.jpg` | 手机端历史记录 | 宽 1280 左右（实机截图） |

手机两张是实机截图，格式为 JPG，命名统一加 `phone-` 前缀以便区分。

> 四张必须**成对**替换：浅色和深色用同一份数据、同一时刻截图，
> 并排放在一起才不会出现数值对不上的尴尬。

## 截图建议

- **测速界面**：选「全部测试」+「多线程」，跑一次完整测速，停在结果页再截图
- **历史记录**：表格有几行数据即可，不必塞满（不出现滚动条时观感更干净）
- 单位统一用 `Mbps`，语言统一用简体中文
- 深浅色切换用顶栏的主题按钮，切到对应模式后重新截同一张
- 两张图的比例、裁剪范围要完全一致

## 格式

- PNG 优先；JPG 也可以，但要改名同步修改 README 里的引用
- 体积建议控制在 500KB 以内（可用 <https://squoosh.app> 压缩）
- 文件名区分大小写，Linux 上尤其注意

## 没有截图时

GitHub 会显示成破图占位。如果暂时不想放，可以把 README 里对应的
`<img>` / `<table>` 段落整段删掉。
