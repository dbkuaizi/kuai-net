# KuaiNet 需求文档

> 页面标题固定为 `KuaiNet`，中文 / English 两种语言下都显示 `KuaiNet`，不翻译。

## 1. 项目目标

提供一个单页面 Web 服务，测量「部署服务器 ↔ 当前浏览器」之间的下载、上传吞吐量和应用层延迟。
测速记录只保存在浏览器本地，服务端不保存任何历史数据。

## 2. 技术方案

- 后端：Go 标准库 `net/http`，无第三方依赖
- 前端：原生 HTML + CSS + Alpine.js + 原生 SVG 仪表盘 + Chart.js 曲线
- 基础样式：[Pico CSS](https://picocss.com) v2，本地静态文件引入；深/浅色沿用 Pico 的 `[data-theme]` + `--pico-*` 变量，自定义样式叠在其上
- Pico 只提供配色与原生控件外观，页面布局仍由 `main.css` 控制
- 资源分发：`go:embed` 将 `static/` 全部嵌入二进制，运行与分发都只需一个可执行文件
- 存储：浏览器 `localStorage`（最多 50 条）；服务端无数据库
- Alpine.js 使用本地静态文件，内网无外网也可正常使用

## 3. 功能需求

### 3.1 测速流程

按勾选的测试类型串行执行（默认三项全选），任一阶段结束自动进入下一阶段：

```text
1. 延迟：连续 10 次 GET /api/ping，得出最小/平均/最大/抖动
2. 下载：4 路并发流式下载
3. 上传：4 路并发 1 MB 分块上传
4. 汇总：延迟 / 下载 / 上传三项结果，写入一条历史记录
```

页面用一个图标按钮切换两个视图（不再有独立 Tab 栏）：

- 测速视图：仪表盘、曲线、控件、结果
- 历史视图：带工具条的记录表格（标题 + 条数 + 导出 / 清空）

顶栏第三个图标随视图变化：测速时显示时钟（点击进入历史），历史时显示小仪表（点击回到测速）；当前视图写入 `localStorage` 的 `netest-ui`。

页面只有一个主卡片：
- 上方：左侧紧凑的仪表盘，右侧实时曲线（图表占更大横向空间）
- 中间：控件行（测试内容、测试参数、速度单位；开始/停止已移到弧中心）
- 下方：一行结果（延迟 / 下载 / 上传 / 传输量与耗时），最后是一行状态文字
不再单独占用控制面板卡片，也不再有独立的“本次结果”卡片。
整体进度条按阶段加权推进（如「下载 2/3 · 45%」），仪表盘随当前阶段切换口径（延迟显示 ms，速度显示 Mbps/MB/s）。

### 3.2 测试类型

| 类型 | 实现方式 |
|---|---|
| 下载 | 4 路并发 `GET /api/download` 流式读取，浏览器累计接收字节 |
| 上传 | 4 路并发 1 MB 随机 Blob `POST /api/upload`，服务端读取后丢弃 |
| 延迟 | 连续 10 次 `GET /api/ping`，计算最小/平均/最大延迟与抖动 |

> 上传不使用 `fetch` 的 ReadableStream 请求体：Chromium 在 HTTP/1.1 下会出现
> `ERR_ALPN_NEGOTIATION_FAILED`，改用固定大小 Blob 分块 POST 更稳定，也不受 chunked 限制。

### 3.3 测试模式

- 持续测速：5 / 10 / 30 秒，按时长结束
- 固定数据量：50 / 100 / 500 MB，按总字节数结束（4 路平分）

### 3.4 过程反馈与结束状态

- 不单独绘制进度条：曲线本身就是进度指示
- 图表下方不再显示任何进度/完成文案（运行中也不显示），仅在出错或未采集到数据时提示；结果统一看上方 Tab
- 顶部状态徽章三态：`就绪`（灰）、`测试中`（绿色呼吸动画）、`已完成`（蓝）、`已停止`（黄）
- 测试结束后：仪表弧与下方读数归零（回到待机状态、量程回 1000 档），但曲线与结果 Tab 的数据保留；顶部徽章变为「已完成 / 已停止」
- 上传使用 `XMLHttpRequest.upload.onprogress` 增量计数，避免低速网络下长时间无进度更新

### 3.5 仪表盘与曲线

- 仪表盘为手绘 SVG：240° 渐变弧 + 内侧刻度值，不画指针、不画刻度短线（弧本身就是进度指示）
- 进度弧使用三套渐变并按阶段切换：延迟黄色、下载绿色、上传蓝色，辉光与读数光晕同步换色，一眼能看出正在测什么
- 弧中心放开始/停止按钮：无背景色、无边框、无 focus 描边，只有 ▶ / ■ 图标（未测时绿色，运行中红色），hover 时轻微放大并发光；图标按外接框居中对齐弧心
- 读数用负 margin 卡进弧的底部缺口：大号数字（不带单位）在上，方向图标 + 单位在下一行
- 数字容器固定高度，位数变化（999 → 9999 → 99999）时只换字号，布局不抖动
- 数字位数较多时自动缩小字号，避免顶到表盘边缘
- 量程按当前峰值自动升档（测试前/过程中实时判断，只升不降）：
  - 峰值 < 1000：最大 1000，刻度 0 / 250 / 500 / 750 / 1k（4 段）
  - 1000 ≤ 峰值 ≤ 2500：最大 2500，刻度 0 / 500 / 1k / 1.5k / 2k / 2.5k（5 段）
  - 峰值 > 2500：最大 10000，刻度 0 / 2k / 4k / 6k / 8k / 10k（5 段）
  - 延迟始终为 0–200 ms
- 刻度沿 240° 弧均分（半径 80），档位切换时重新排布
- 峰值超过 10k 时弧打满，真实数值仍由下方读数完整显示
- Chart.js 折线图实时绘制：
  - 下载/上传：x 轴为秒，y 轴为当前速度单位，带渐变填充
  - 下载与上传为两条独立数据线（绿/蓝），共用同一条时间轴便于对比
- 采样频率 10Hz（100ms），速度取最近约 300ms 的滑动窗口，避免锯齿与跳帧
- Chart.js 只对 y 轴做 120ms 线性过渡，x 轴立即到位，曲线呈现连续生长而不是一帧一帧地瞬移
- 持续模式 x 轴范围固定为测试总时长（如 10 秒），曲线从 0 秒开始向右生长，x 轴不会随时间不断重算
- 固定数据量模式的 x 轴按实际耗时自适应
- 只跑单项时另一条曲线自动隐藏
- 单位切换时曲线数据按原始 Mbps 重新换算，无需重测
- 极快的测试在结束时补一个收尾采样点，且 x 保证单调递增

### 3.6 主题与语言

- 顶栏右侧三个纯图标按钮（无边框、无底色、无选中态；hover 只让图标变亮）：主题、语言（地球）、视图切换（时钟 / 小仪表）
- 主题：三态循环 `auto → light → dark → auto`，默认 `auto`
  - `auto` 读 `prefers-color-scheme`，并监听其变化实时跟随；图标是显示器（表示跟随设备）
  - 实际生效主题写入 `<html data-theme>`，复用 Pico 的 `[data-theme]` 变量体系
  - 选择写入 `localStorage.netest-theme`
  - `static/theme-init.js` 在 `<head>` 中同步执行（无 defer），首帧绘制前就设置好 `data-theme` 与 `lang`，避免深色模式刷新时闪白
- 语言：中文 / English，默认跟随浏览器 `navigator.language`，切换后写入 `localStorage`
- 切换主题时同步更新 Chart.js 的坐标轴、网格、图例颜色；切换语言时同步更新图例与坐标轴标题
- 点击历史图标平滑滚动到「测速记录」并高亮卡片

### 3.7 结果显示

- 实时速度（每 200 ms 采样）
- 平均速度、峰值速度、已传输字节数、耗时
- 延迟：最小 / 平均 / 最大 / 抖动 / 探测次数
- 速度单位切换：`Mbps` / `MB/s`（内部统一 Mbps，切换只影响显示）
- 数据量显示自动使用 B / KB / MB / GB

### 3.7 中止测试

- 测试进行中按钮切换为「停止测试」，点击即中断所有在途请求
- 停止瞬间快照已传输字节数与耗时，用快照计算平均值，不把请求收尾时间算进测试时长
- 已采集到数据则写入历史记录，并标记 `stopped: true`（表格显示「类型 · 中止」）
- 未采集到数据则不写入记录，仅提示「已停止，未传输数据 / 未采集到延迟数据」
- 测试进行中锁定测试类型与参数下拉框，避免参数被中途修改

### 3.8 历史记录

- 一次完整测速保存为一条记录，包含 `latency` / `download` / `upload` 三个子对象（页面结果行与表格读同一份数据）
- 旧版扁平记录（`speed`/`peak`/`bytes`）在读取时自动迁移
- 浏览器 `localStorage` 保存最近 50 条，中止的记录会带「中止」标记
- 表格展示时间、类型、平均、峰值或抖动、传输量
- 支持导出 JSON、清空
- 服务端不记录、不落盘

## 4. 接口

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/api/ping` | - | 返回 `ok` |
| GET | `/api/download` | `duration` 秒、`size` 字节 | 返回 `application/octet-stream`，`Content-Encoding: identity`，256 KB 分块 flush；`size=0` 时仅按时长结束 |
| POST | `/api/upload` | `duration` 秒、`size` 字节 | 读取并丢弃请求体，返回 `{"bytes":N}` |
| GET | `/` | - | 嵌入式页面 |

所有响应带 `Cache-Control: no-store`、`X-Content-Type-Options: nosniff`、
`Content-Security-Policy: default-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-eval'; connect-src 'self'`。

## 5. 安全与资源限制

- 服务端单次时长上限：默认 60 秒（`-max-duration`）
- 服务端单次数据量上限：默认 1 GiB（`-max-size`），超出的 `size` 会被裁剪
- 上传内容不写磁盘，仅计数
- 不提供任意 URL 访问、命令执行、网段扫描
- 不开启压缩，避免测速数据被压缩影响结果
- `ReadTimeout` / `WriteTimeout` 70 秒，`ReadHeaderTimeout` 5 秒
- 前端同一时刻只允许一组测试运行

## 6. 启动与配置

```bash
./netest -addr :8080 -max-duration 60 -max-size 1073741824
```

浏览器访问 `http://服务器IP:8080`，需要能访问该端口。

## 7. 验收标准

- `go build` 产出单一可执行文件，运行时无需外部静态文件
- `go test ./...` 通过（接口、embed 资源、CSP、限流参数）
- 页面可完成下载 / 上传 / 延迟三类测试，控制台无报错
- 持续模式与固定数据量模式均能按预期结束
- 单位在 Mbps 与 MB/s 间切换时数值同步换算
- 刷新页面后历史记录仍在；服务端重启不会产生历史文件

## 8. 非目标

- 不测任意目标地址、不做网段扫描
- 不做 ICMP Ping、traceroute
- 不做多服务器对比、自动节点选择
- 无用户系统、无服务端历史、无公网测速
